# The Bible, Like Totally — archived static site

This repository holds the original static HTML/CSS design of thebibleliketotally.com.
The live site now runs on WordPress (theme "The Bible, Like Totally"), and `www.thebibleliketotally.com` points to WordPress, not GitHub Pages.
These files are kept as a design reference only. Do not re-add a `CNAME` file.

## WordPress theme backup
The current source of the live WordPress theme is in `wordpress-theme/tblt-theme/` (see `style.css` for the version). It is backed up here after every theme release. To restore, zip the `tblt-theme` folder and upload it at Appearance → Themes → Add New → Upload Theme.

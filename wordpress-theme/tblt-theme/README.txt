THE BIBLE, LIKE TOTALLY - WordPress theme v1.0

INSTALL: Appearance > Themes > Add New > Upload Theme > choose tblt-theme.zip > Install > (Preview first, then Activate).

PAGE TEMPLATES (Page > Page Attributes > Template):
  Home .............. create a page "Home", set it as the front page (Settings > Reading). front-page.php is used automatically.
  Old Testament ..... existing page /old-testament/  -> "Old Testament (TBLT)"
  New Testament ..... existing page /new-testament/  -> "New Testament (TBLT)"
  All 66 Books ...... new page, slug all-books       -> "All Books (TBLT)"
  About ............. existing page /about/          -> "About (TBLT)"
  Join .............. new page, slug join            -> "Join (TBLT)"
  Contact ........... existing /totally-contact-us/  -> "Contact (TBLT)"
  Terms ............. existing /terms-of-use/        -> "Terms of Use (TBLT)"
  Privacy ........... existing /privacy-policy/      -> "Privacy Policy (TBLT)"
All other pages (book pages, ProfilePress login/sign-up/checkout/account) use the default page.php, wrapped in the same header and footer.
Content of the designed pages lives in the template files (edit the PHP files to change their text).
